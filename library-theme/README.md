# Тема WordPress: Biblioteka19

Тема для сайта «Летопись поселка ЛВРЗ» — Библиотека-филиал №19 МАУ ЦБС г. Улан-Удэ.

---

## Установка

1. Скопируйте папку `biblioteka19` в `/wp-content/themes/biblioteka19/`
2. В панели WordPress: **Внешний вид → Темы** — активируйте «Biblioteka19»
3. Скопируйте файлы изображений из вашей старой папки `assets/images/` в `/wp-content/themes/biblioteka19/assets/images/`

---

## Первичная настройка

### Логотип
**Внешний вид → Настроить → Логотип сайта** — загрузите логотип (`logo.png`)

### Изображение «глаз» (версия для слабовидящих)
Поместите файл `eye.png` в `assets/images/eye.png` темы.

### Меню навигации
**Внешний вид → Меню**:
- Создайте меню
- Добавьте в него разделы летописи (они появятся после добавления записей)
- Назначьте меню на расположение **«Левое боковое меню»**

### Ссылки на социальные сети
**Настройки → Чтение** → раздел «Социальные сети» — вставьте нужные URL.

---

## Добавление контента

### Разделы летописи
В боковом меню WordPress появится пункт **«Разделы летописи»**:
- Создайте записи для каждого раздела (Предисловие, История микрорайонов и т.д.)
- Установите порядок отображения через поле **«Порядок»** (Menu Order) в настройках записи
- Первая запись (Menu Order = 0) будет отображаться на главной странице

### Афиши (правая колонка)
В меню WordPress появится **«Афиши»**:
- Создайте запись-афишу
- Загрузите **миниатюру** (изображение афиши)
- В поле **Произвольные поля** добавьте поле `_poster_url` со ссылкой ВКонтакте или другой

## Структура файлов

```
biblioteka19/
├── style.css                    ← Обязательный заголовок темы
├── functions.php                ← Подключение стилей, типы записей, AJAX-поиск
├── index.php                    ← Главная страница
├── page.php                     ← Обычная страница
├── single-letopis_section.php   ← Страница раздела летописи
├── search.php                   ← Страница результатов поиска
├── 404.php                      ← Страница ошибки
├── header.php                   ← Шапка
├── footer.php                   ← Подвал
├── sidebar.php                  ← Левая колонка (меню, поиск, соцсети)
├── template-parts/
│   └── aside-posters.php        ← Правая колонка с афишами
└── assets/
    ├── css/
    │   └── stele.css            ← Ваши стили (без изменений)
    ├── js/
    │   └── main.js              ← Поиск и полноэкранный режим
    └── images/                  ← Скопируйте сюда свои изображения
```

Кнопка «Версия для слабовидящих» уже встроена в шапку.

## Контактная информация в подвале

Настраивается через **Настройки → Чтение** (добавятся после сохранения раздела «Социальные сети»).  
Либо напрямую в `footer.php` замените значения по умолчанию в `get_option(...)`.
